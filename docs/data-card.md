# Data Card: Flight Delay Training Sample

## 1. Назначение и запрещенные сценарии
* **Назначение:** Учебный синтетический набор данных (`flights_sample.csv`) предназначен для отработки процессов валидации данных, проверки контрактов и настройки MLOps-инфраструктуры.
* **Запрещенные сценарии:** Набор не предназначен для принятия реальных операционных решений авиакомпаний или прогнозирования задержек рейсов в реальном мире.

## 2. Происхождение и владельцы
* **Источник:** Синтетический учебный датасет для курса MLOps.
* **Владелец команды:** Команда team-2 (ответственный за карточку: @Vikabh).

## 3. Состав полей и целевая переменная
Набор содержит 24 строки и следующие поля:
* `DepHour`: целое число от 0 до 23 (час отправления по местному времени, признак).
* `IsWeekend`: признак выходного дня, строго принимает значения 0 или 1 (признак).
* `ArrDelay`: задержка прибытия в минутах, целое число от 180 до 1440 (источник для формирования целевой переменной).

> **Важно (Предотвращение утечки данных):** 
> Целевой класс формируется условием `ArrDelay > 15`. Сам исходный столбец `ArrDelay` **строго запрещено** использовать в качестве входного признака (`FEATURES`) для модели, так как это приведет к прямой утечке целевой переменной (data leakage).

## 4. Стратегия разделения данных
* Используется случайное стратифицированное разделение (`random_state=42`) с учетом баланса целевого класса.

## 5. Версионирование и конвейер данных (ЛР3)

- **Версионирование через DVC**: Исходный набор данных `data/flights_sample.csv` зафиксирован в Git и отслеживается с помощью DVC.
- **Стадии конвейера**:
  - `validate`: проверка входящих данных по контракту (`data/contract.json`).
  - `preprocess`: очистка данных и формирование бинарной целевой переменной (`ArrDelay > 15`).
  - `split`: стратифицированное разделение на обучающую (`train`) и тестовую (`test`) выборки с фиксированным `random_state=42`.
- **Предотвращение утечек данных (Data Leakage)**:
  - Целевая колонка `ArrDelay` строго исключена из списка входных признаков (`FEATURES`).
  - Масштабирование признаков (scaler) обучается **исключительно на тренировочной выборке (`train`)** и применяется к тесту через сохраненный объект `models/scaler.pkl`, чтобы исключить утечку информации из тестового набора.
