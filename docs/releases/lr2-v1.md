## Источник данных и разрешённое использование

Файл `data/flights_sample.csv` (24 строки, поля DepHour, IsWeekend, ArrDelay) описан в методичке ЛР2 как учебный синтетический набор, но в стартовом проекте он не найден. Команда сгенерировала аналогичный образец с помощью нейросети по описанию полей и диапазонов из методички (PR #22): значения случайные, укладываются в допустимые диапазоны, оба класса цели (ArrDelay > 15 и ArrDelay <= 15) присутствуют. Персональных данных нет, набор предназначен для проверки инфраструктуры, а не для выводов о реальных рейсах. Владелец и ответственный за обновление: <кто, по карточке данных>. Подробности: `docs/data-card.md`.

## Контракт данных

- Файл: `data/contract.json`, версия контракта: <версия из файла, ожидается 1.0.0>
- Поля: DepHour (целое, 0–23), IsWeekend (0 или 1), ArrDelay (целое, −180–1440, источник цели)
- Правила: минимум 20 строк, лишние столбцы и полные дубликаты запрещены
- Правило версионирования: patch (описание без изменения проверки), minor (необязательное поле), major (удаление, переименование, смена типа или смысла)

## Команда успешной проверки

```
python -m mlops_project.validate_data --data data/flights_sample.csv --contract data/contract.json --report reports/validation/lr2.json
```

Результат: код завершения 0, `passed: true` в отчёте. Отчёт приложен к GitHub Release.
