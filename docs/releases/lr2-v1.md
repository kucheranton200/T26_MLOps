## Источник данных и разрешённое использование

Файл `data/flights_sample.csv` (24 строки, поля DepHour, IsWeekend, ArrDelay) описан в методичке ЛР2 как учебный синтетический набор, но в стартовом проекте он не найден. Команда сгенерировала аналогичный образец с помощью нейросети по описанию полей и диапазонов из методички (PR #22): значения случайные, укладываются в допустимые диапазоны, оба класса цели (ArrDelay > 15 и ArrDelay <= 15) присутствуют. Персональных данных нет, набор предназначен для проверки инфраструктуры, а не для выводов о реальных рейсах. Происхождение, владелец и правила обновления описаны в `docs/data-card.md`.

## Контракт данных

- Файл: `data/contract.json`, версия контракта: 1.0.0
- Поля: DepHour (целое, 0–23), IsWeekend (0 или 1), ArrDelay (целое, −180–1440, источник цели)
- Правила: минимум 20 строк, лишние столбцы и полные дубликаты запрещены
- Правило версионирования: patch (описание без изменения проверки), minor (необязательное поле), major (удаление, переименование, смена типа или смысла)
- Поле ArrDelay добавлено в контракт отдельным исправлением (PR #36): без него валидатор отвергал корректный файл

## Команда успешной проверки

```
python -m mlops_project.validate_data --data data/flights_sample.csv --contract data/contract.json --report reports/validation/lr2.json
```

Результат: код завершения 0, `passed: true`, 13 проверок пройдены. Отчёт приложен к GitHub Release.

## Контрольная сумма

SHA-256 файла `data/flights_sample.csv` (214 байт):
`a828de7d3c87377c9bd247ae97ffc59ad90aa39dd43fa376380381c572268cbe`

Значение в отчёте валидации совпадает с этой суммой. Для воспроизведения на Windows нужна настройка `git config --global core.autocrlf false` до клонирования: иначе окончания строк меняются, и сумма отличается.

## Стратегия разделения данных

Случайное стратифицированное разделение по классу задержки, `random_state=42`. `ArrDelay` используется только для построения цели (`ArrDelay > 15`) и не входит в признаки. Преобразования обучаются только на train. Подробности: `docs/data-card.md`.

## Ограничения

- Набор синтетический и небольшой (24 строки), выводы о реальных рейсах не делаются.
- Остальные ограничения набора описаны в `docs/data-card.md`.
